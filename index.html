機能

外部サーバーには一切送信しません。データはブラウザの中だけに保存されます。

3つのAIで同じプロンプト

ChatGPT、Claude、Gemini のどのページでも同じ一覧が使えます。右下の ✎ ボタン、または Alt+Shift+P。

/ショートカットで即展開

プロンプトに短い名前を付けておけば、入力欄で「/名前」+スペースと打つだけで本文に置き換わります。

穴埋め変数と自動変数

{{変数}} で穴埋め、{{日付}} {{クリップボード}} {{選択テキスト}} は挿入時に自動で埋まります。

日本語テンプレート集

ビジネス、ライティング、学習、プログラミングなど26種のテンプレートをワンクリックで追加。

どこからでも保存

入力欄に書いた文章をそのまま保存。Webページ上の文章は右クリックからプロンプトに。

フォルダ・お気に入り・検索

フォルダ分け、★お気に入り、最近使った順、使用回数。増えても迷いません。

よくある質問

プロンプトの内容はどこに保存されますか?

お使いの Chrome の中(拡張機能のローカルストレージ)にだけ保存されます。当方のサーバーには送信されません。

購入後に別のパソコンでも使えますか?

使えます。設定画面の「購入済みの方はこちら」から、購入時のメールアドレスでログインすると Pro が復元されます。プロンプト自体は JSON エクスポート/インポートで移行してください。

返金はできますか?

購入から14日以内で、不具合により正常に利用できない場合は返金に応じます。下記の連絡先までご連絡ください。
